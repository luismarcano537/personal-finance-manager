# Personal Finance Manager

A full stack personal finance management application built with ASP.NET Core, React, PostgreSQL and Docker.

## Status

In development.

## Overview

This project is being built to practice and demonstrate full stack development skills using .NET, relational databases, authentication, API design, documentation and deployment.

The application will allow users to manage income, expenses, categories and monthly financial summaries.

## Tech Stack

### Backend
- C#
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- JWT Authentication
- Swagger

### Frontend
- React
- JavaScript
- Axios
- HTML/CSS

### Infrastructure
- Docker
- Docker Compose
- GitHub

## MVP Features

- User registration and login
- JWT authentication
- Category management
- Income and expense management
- Monthly financial summary
- Basic dashboard
- API documentation with Swagger
